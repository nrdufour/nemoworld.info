# originals/

Full-resolution originals of the images published under `static/`.

Kept in the repo because for several of these photos **this is the only copy**
that exists: `static/` holds the optimised, web-sized version that visitors
download, and `originals/` holds the file exactly as it came off the camera.

Hugo does not publish this directory - only `static/` and `themes/*/static/`
are copied into the site - so nothing here is ever served.

Before replacing a file here with a smaller version, make sure the master
exists somewhere else.
